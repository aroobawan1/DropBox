# DropBox Clone – File Upload App

A full-stack Dropbox-style file upload and management system built with React and a backend API, using AWS S3 storage for secure and scalable file handling. It supports file upload, file listing, download, and deletion. The project is containerized using Docker for easy deployment.

---

## Features

- Upload files via drag & drop or button
- View uploaded files list by clicking load files button
- Download files by double clicking on file
- Delete files by clicking cross next to each file
- REST API backend 
- AWS S3 Storage used
- Docker support for easy setup

---

**Frontend**
- React (Vite)
- JavaScript
- HTML / CSS

**Backend**
- Python (Flask / FastAPI)
- File handling API
